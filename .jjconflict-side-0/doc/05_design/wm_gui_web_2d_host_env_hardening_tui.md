# Test Host Environment TUI Design

The command emits stable `key=value` rows suitable for operators and parsers.

```text
TEST_HOST_ENV schema=simple-test-host-env-v1 status=blocked
capability=x86_simd status=pass reason=native-bit-exact evidence=...
capability=arm_simd status=blocked reason=requires-aarch64-host resume=...
capability=riscv_simd status=blocked reason=requires-riscv64-rvv-host resume=...
capability=vulkan status=pass reason=device-readback evidence=...
capability=renderdoc status=blocked reason=renderdoc-unavailable resume=...
capability=display_input status=pass reason=winit-x11-live evidence=...
capability=framebuffer_readback status=pass reason=correlated-argb evidence=...
```

No color or cursor control is required. Full paths are retained in the artifact
report; terminal output remains bounded.
