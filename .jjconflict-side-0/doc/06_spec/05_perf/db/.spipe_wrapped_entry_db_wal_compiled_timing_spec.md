## Overview

    These scenarios record compiled-mode timing evidence for the in-process DB WAL
    MVCC core. The script-mode DB benchmark still omits WAL timing because the
    interpreter lacks the required `Array.remove` path; this spec is intended to run
    with `bin/simple test --mode=native`.

    ## Requirements

    **Requirements:** doc/02_requirements/feature/gpu_web_db_offload.md

    - WAL timing evidence must be measured in a compiled-capable path instead of
      being represented only by interpreter-mode omissions.
    - The benchmark report must include an explicit row for WAL insert plus visible
      row count validation.
