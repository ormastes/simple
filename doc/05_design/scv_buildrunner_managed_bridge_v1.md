# BuildRunner managed bridge V1

Tests are authored before implementation. Runtime execution: **NOT_RUN**;
there is no admitted general-purpose runtime for these feature specs.

The existing source session remains canonical. A managed task additionally
requires authenticated task-context V2 target-layout and configuration digests.
V1 contexts remain source-only and persist an explicit unavailability reason.
Compiler digest is the exact task producer executable digest; it is not a
compiler live-owner semantic handle. No semantic receipt is synthesized.

The bridge freezes only the finite declared regular task-input set: actual
compiler frozen-inventory bytes for source roles, and no-follow digest-checked
bytes for ordinary roles. Logical mode 420 describes the private normalized
staging representation; it does not certify physical source modes. Paths are
exact file scopes, never arbitrary directory/absence coverage. Sources keep
their existing source-only witness validation. Editor, generated, external,
physical alias/mode/event and actual semantic producer domains remain unavailable.

Capture/feed cursors cover this parent-owned immutable logical set only. They
cannot establish physical no-change. Unknown capture remains unknown. Every
task admission, cache/retry/resume and verification path goes through the
existing session checker, which checks the exact managed subject and retained
record too. Private worker staging contains the pinned bytes for every task
input; transport retains its existing digest/no-follow verification.

An empty derivation graph is bookkeeping only. Until the actual compiler owner
emits validated outgoing-use evidence, no consumer or receipt is published and
the bridge reports compiler-semantic-producer unavailable. No second scheduler
or accepted semantic root is introduced. Broader all-domain integration remains
incomplete. Parent alone owns any later durable graph publication/CAS.

This bridge never invokes managed eviction or source GC. Its private staging
roots remain retained with the session; no active lease is released early.
Shared retention-store root admission/pinning and worker-reap lease release
remain a separate required integration before enabling managed eviction.

Durable records bind capture unknown reason, retired epochs/history digest,
and feed floor/event IDs. This initial production profile accepts sequence zero,
no events and no retired epochs only; it cannot reopen advanced/reconciled
histories. Unknown state is durably poisoned before production refusal. A later
fresh constructor cannot overwrite that marker: exact retained-record comparison
fails. Recovery requires a new explicitly owned run/state directory until a
real producer reconciliation/replay owner is integrated. No field reset clears
a gap or permits A→B→A epoch reuse.
