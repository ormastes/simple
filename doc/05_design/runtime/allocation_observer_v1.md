# Native allocation observer v1 — bounded implementation

Design authority: `/home/yoon/dev/phase3-restart-clean-20261021/acceptance-plan/allocation-observer-design.md`, assessed at `5793f5acd7ecdf6cd34d97f3fd295c489997fd4a`.

Select `--runtime-bundle core-c-alloc-observer-v1` on a native Linux host with canonical C runtime owners. This selects fresh core-C objects, adds `SIMPLE_ALLOC_OBSERVER_V1=1`, and changes the runtime object-cache key and compilation context. Runtime archive paths, native-all, Stage4, Rust owners and cross targets are rejected. Other source-list consumers include the disabled ABI owner only; they do not admit the instrumented profile. Compile/link admission is necessary, but not sufficient for an executable closure claim.

The ABI is `rt_alloc_probe_reset_v1`, `rt_alloc_probe_count_v1`, `rt_alloc_probe_coverage_v1`; `std.log` forwards to it. Coverage `65551` is version 1 plus malloc/calloc/realloc/sampled-mmap capability bits. It covers owned operations in `runtime_memory.c` and `runtime_native.c`, including registry growth and native wide-integer/float boxing. It does not certify external providers or arbitrary generated code. Enabled observer linking requires both instrumented-owner anchors. Disabled code aliases allocation sites directly to libc, reports coverage zero and count -1.

One fixed initial-exec TLS record stores total, baseline, baseline-valid and sticky overflow. Successful nonnull libc acquisitions count, including in-place realloc and zero-size nonnull returns. Guard mappings count immediately after mmap succeeds, before protection can roll back. Free never decrements; facade returns never double count. Provider errno is preserved. Unsigned total overflow stays invalid across resets. Deltas beyond signed 61-bit immediate payload report -1 to avoid boxing a snapshot. Reset/count allocate no explicit storage and contain no registry, locks, formatting, callback or environment reads.

Only startup-linked, dedicated single-carrier processes are candidates for admission. No late dlopen, task migration, concurrent specs, nested reset, signal-handler manipulation, or process-wide/pool allocator claims. Inspect emitted TLS access and the exact generated reset/push/drain/snapshot closure before admission; reject reachable allocation owners not covered by these hooks. Preserve the epoch-nanosecond timestamp: tagged lowering can allocate a wide integer and must fail the zero-event contract when it does.
