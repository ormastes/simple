# Default symbol inventory prerequisite

Status: implementation for independent source review. Seven new controls and
the strengthened scheduler capture control are authored UNRUN. No decoder
replay getter, driver activation, binding-validity receipt or general default
completion is introduced.

The actual selected ordinary default recorder now encodes the successfully
relocated expression with an opt-in writer-owned inventory. The generator
threads each declaration/variant/field role to SymbolId encoding. The collector
retains occurrence order, schema role, presence and the raw scalar value;
absent pre-link references and negative unresolved sentinels remain explicit
data and never cause invented symbol records. Repeated references remain in
the occurrence stream.

The same account prepays collection work and conservative array replacement
growth. Failure poisons the writer before appending; generated entry/loop
guards stop traversal immediately. The collector is a nullable nominal field,
so ordinary disabled writers acquire no Optional box, inventory array or scan.
Existing byte grammar remains unchanged. Schema generator and checked-in
artifact carry the same role/absence hooks; no code generator was executed.

The MIR helper walks only referenced nonnegative target IDs using an accounted
deduplicating queue. Before each actual target map lookup it pays the native
live-count observation and collision multiplicity. Each matching real symbol
record is serialized into retained bytes using a fresh writer attached to the
same account. Its type references extend the queue, including self/mutual
nominal cycles without revisiting a record. The result retains scalar IDs and
encoded text, never a mutable HirSymbol alias. Missing or mismatched real map
entries refuse without returning a partial observation.

The actual recorder binds this data to its current selected original, ordered
default occurrence and target lifetime selector. Existing actual builder-owner
checks run before capture. The target selector is comparison data, not archive
admission. The private driver must still bind the actual loaded target and
clear all retained state on every exit before promotion/end.

This inventory does NOT cover all metadata consulted by lowering. Field
layouts/default records, callable ABI/default/method registrations, enum
runtime/payload rows and global storage/initializers still need their actual
operation-boundary observations and before-use validation. Reusing encoded
lexical IDs also requires the original-function namespace and exact ordered
replay proof. Unrelated legitimate target-symbol additions are not invalidated
by a whole-table hash; no such hash is used here.

Controls exercise actual frontend nested defaults/repeated references, actual
allocated target records with a cyclic nominal type graph, immutable encoded
snapshots, target key mismatch, exact/one-short account growth, immediate stop
after poison, explicit absent/sentinel roles and disabled byte equivalence.
They do not qualify native capacity, memory consumption, performance, whole
module codec traversal or end-to-end SOURCE execution.
