# Versioned numeric user selection and native mapping observation

Status: IN_PROGRESS / UNEXECUTED. Source assertions are authored; no runtime, native mapping or storage authorization is qualified.

An absent selection (`user_uid=-1`, `user_gid=-1`, empty namespace mode) preserves the exact existing V1/V2 digest and retained-request bytes. A selected request requires both canonical numeric IDs in 0..4294967294 and `keep-id`, uses digest/codec version 3, and records terminal mode explicitly. Old versions reject new fields. Podman create emits separate typed `--user UID:GID` and `--userns=keep-id` arguments. Docker/runc selection is refused. Changing or removing the selection changes the immutable bound request and cannot replay a prior operation.

Selection is not evidence. The producer requires a strict V2 bound intent and exact full64 runtime identity, then performs bounded object-kind-specific `container inspect` queries before and after the native observation. A flat JSON template JSON-escapes all original identity labels, native ID, Config.User, running state, PID and CgroupPath. Strict parsing rejects duplicate/unknown/missing fields, nested values, trailing records and noninteger/invalid PIDs. Config.User must equal the explicit numeric pair. Canonical cgroup paths must contain an exact `libpod-ID`, `libpod-ID.scope` or `libpod-payload-ID` component; the native owner must independently match the exact whole path rather than assuming nested membership.

The native binding hashes the canonical request digest, complete runtime identity and scope fence, current provider pin, selected IDs/namespace, and actual routed pre-query operation/evidence. The producer invokes the canonical `linux_container_user_observe_v1`, re-inspects the exact container and refreshes the same opaque native token. Container UID/GID must equal selection, and process birth identity, maps, namespaces, host mappings and observer identities must remain unchanged. Rootless host EUID, Config.User or a signed boolean cannot replace those observations. Scripted providers are explicitly refused before native acquisition.

Every descriptor owner survives uncertainty. Outcomes carry observed facts plus native observation, cleanup-required native observation, or initial acquisition failure with retained native token. Any post-query/selection/refresh failure closes through the canonical native owner; an unconfirmed close returns the owner rather than dropping it into a text error. No token is serialized or reconstructed from facts. Cross-thread refresh may be unsupported by the native owner and must fail closed.

This capability observes an already-running primary process. It cannot authorize chmod of a primary ENTRYPOINT before start, and does not enable the remote producer until a real staged bootstrap/exec or prestart namespace design exists. Storage separately requires `file.uid == native observer EUID == actually mapped execution UID` (and its filesystem-ID checks); this slice grants no 0755/ACL widening or owner-execute bypass.

Primary evidence: [Podman user selection](https://docs.podman.io/en/latest/markdown/podman-run.1.html), [inspect state definition](https://github.com/podman-container-tools/podman/blob/v5.2.5/libpod/define/container_inspect.go), [Linux status credentials](https://man7.org/linux/man-pages/man5/proc_pid_status.5.html), [UID namespace mapping semantics](https://man7.org/linux/man-pages/man7/user_namespaces.7.html). HostConfig.UsernsMode is not used as proof of keep-id.

The actual common mapping facade and owner-returning close composition are implemented through `std.nogc_async_mut.container.user_mapping_v3`; audit receipts are defined separately in the common contract module and never decode native authority. Current authored evidence comprises five selection/compatibility cases and six parser/pre-native/common producer cases, all UNEXECUTED. Common refusal preserves its original container owner and returns no invented mapping owner. Actual pinned native observation, cleanup failure retention, pre/post race refusal, successful mapping-owner transfer and storage authorization still require native acceptance evidence. The native observer dependency is immutable commit `197a3eeee4db9a6b1677e528df40b2258a2223da`; no native framework source was copied into this slice.
