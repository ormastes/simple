# Stage 3 explicit RSS cap transport

An explicit canonical `SIMPLE_BOOTSTRAP_PROCESS_TREE_RSS_CAP_KIB` is independent of compiler-ceiling elevation. The resume owner resolves it against the existing static/jobs/real-host hard ceiling before launching the existing worker, includes it in the new invocation hash, and passes its exact value positionally across systemd. The worker rejects ambient conflicts and re-resolves the actual command jobs under enforced real policy before execution.

The same cap is an explicit command-transcript/environment row, survives `env -i`, feeds the process-tree watchdog and supplies the child frontend budget. Case-insensitive duplicate/conflicting/missing Stage 3 cap rows are refused. Canonical transcript readers reconstruct only recorded cap rows in the existing verification vectors. Historical vectors with no row remain absent; no current shell environment is imported into their identity.

The ordinary static ceiling remains 50331648 KiB. A 33554432 KiB cap needs no elevation variable or 75% fresh-availability elevation check. The existing elevated-ceiling policy is unchanged and still requires an actual increase above its prior ceiling, real total/available headroom, explicit jobs and enforcement. Host/resource admission, cgroup bounds, RLIMIT_AS, watchdog mode and descendant cleanup remain mandatory independent owners.

One exact historical default stays unchanged: the Darwin launcher installs an internal 6835937 KiB enclosing cap after hashing its old vector. Only actual Darwin, a Darwin target, empty positional cap/no ceiling and that exact value retain the old ambient/default route and no new cap row. Other unrecorded ambient caps are refused. A user-explicit cap, including the same numeric value, is resolved and transported before hashing and uses the new recorded route.

Focused shell fixtures execute the actual resume-selection block, existing worker and transcribed `env -i` dispatch with an inert shell probe. They check the complete parent/worker command hash, cap/frontend/watchdog equality, explicit identity, absent default, malformed/over-ceiling/ambient conflicts and transcript duplicate/missing-row rejection. They do not compile a native program or qualify a compiler.
