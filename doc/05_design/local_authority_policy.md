# Local authority policy loading

`LocalAuthorityPolicyV1` returns a validated `DistributedAuthoritySnapshotV2`, session generation and source digest. The canonical document contains version, generation, policyRevision, revocationEpoch, sessionGeneration and a bounded key registry. Each registry row contains the existing public key/role/revision/scope/operations/budget/expiry/revocation metadata. There are no signing keys, clocks, enrollment flags or continuity assertions. Unknown fields reject. Existing snapshot construction and signature verification remain the sole validation/crypto owners.

`local_authority_policy_decode_v1(bytes)` caps UTF-8 bytes before parsing, requires canonical encoding, caps key/operation counts and hex lengths before allocation, and delegates key validation. `local_authority_policy_load_v1(root, expected_digest)` caps and validates its path/pin, checks real nofollow directory components, requires root mode 0700 and a private regular policy file, reads at most 1 MiB and verifies the external digest before decoding. It reads only `authority-policy.sdn`; it does not publish or mutate policy.

The caller must already own the root created by `secure_temp_dir` and its trusted ancestor tree. No inspected UID getter or race-free descriptor-relative filesystem owner is available here. Permission and pathname checks do not authenticate arbitrary roots and do not eliminate ancestor replacement races. The actual host-local initializer must establish that prerequisite and pin the digest independently; this loader cannot manufacture it. Current path rules target the approved Linux-local command subset.

The source specification checks actual canonical values and error reasons, real secure-directory file permissions, tamper-before-decode refusal and real symlink root/leaf refusal using the existing package symlink facade. Cleanup unlinks the exact owned links before deleting its private test directory. The manual is authored, not generated evidence; compilation and runtime tests are NOT_RUN. This component cannot satisfy live host execution acceptance by itself.
