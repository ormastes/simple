and retained artifacts. No workload, QEMU, browser, socket, OpenSSH, pgbench,

## Completion decision

The objective is not complete. The DB build/closure gate is now green, but its
first rooted artifact crashes before readiness; the web build gate remains RED.
The nearest critical path is: fix native liveness, exercise both artifacts on
Linux, retain matched nginx/PostgreSQL measurements, then build the separate
SimpleOS target artifacts and stage those exact hashes into a filesystem-launch
QEMU run. Browser, SSH, hybrid-PQC, and GPU claims must be measured over those
live paths rather than inferred from in-memory adapters, policy tests, or
kernel-only evidence.
