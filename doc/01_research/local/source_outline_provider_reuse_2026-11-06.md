# Reusing source-outline providers on release/1.0.0

Inspection base: frozen 77b05b3, extended in the isolated next worktree. Execution is not yet admitted.

- Simple: `src/compiler/10.frontend/treesitter/outline.spl` has a token-based native parser and a separate explicitly selected heuristic branch. `treesitter_new` sets `heuristic_mode=false`; the new adapter keeps that value. This is Simple's own outline implementation, not an installed external Tree-sitter library. `FunctionOutline.span/body_span`, container/member spans and `LexSpan` supply byte mappings. `app/cli/query_outline.spl` instead uses line-prefix heuristics and is not substituted for native proof.
- Native prerequisite: `skip_block` used depth one even without an Indent token and could consume later declarations after inline bodies. The canonical owner now branches at logical newline/EOF for inline bodies, preserving opaque-block and inline-asm handling. Runtime proof remains pending; see the claimed inline-body bug.
- SDN: `common/sdn/parser.spl` exports `parse_with_spans_and_issues`, but populates `SdnSpan.at(line,col)`. The current value type contains start/end fields, yet `at` initializes both to zero. Native lexer tokens carry kind/text, not source byte ranges. Exact block folding needs the canonical SDN span owner extended; canonical encoding would erase comments/order and is unsuitable as source evidence.
- SHS: `src/os/apps/shell/shell_script.spl` parses the Simple/sosh dialect, but returned Stmt objects have no source spans and do not establish POSIX/Bash semantics. The driver normalization adapter documents a historical StmtKind co-import collision. That claim needs a current co-import regression; it was not reproduced in this lane. The referenced historical bug file is absent in this checkout. Do not invent dialect or source ranges, execute shell code on read, or claim the historical collision is freshly verified.

The native adapter remains in compiler tools; common contracts and no-GC projection do not import compiler internals. Public app/source_view/service composes IO, native provider and projection for both MCP and authenticated Caret HTTP.

Further canonical import findings: KwUse was omitted from outline dispatch; grouped/star suffix dots were consumed before parse_import expected them; leading relative dots failed identifier parsing. The assigned owner now handles these forms and retains alias processing. The dispatcher's attribute type annotation was also corrected to its actual AttributeOutline return type. Exact and adjacent regressions are authored, NOT_RUN.
