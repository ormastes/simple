# ctor class MIR failures under stage2 (2026-10-31)

Class `ctor` (enum construction / record payload). Workaround tag: `# @workaround bug=ctor-mir-20261031`.

## Root bugs (stage2 MIR / HIR)

1. Generic-typed `Result` from `SimpleRing<i64,i64>.create(...)` and from generic-self methods
   (`provider_take`, `take_completion_retained`) keeps unsubstituted `Op`/`Cpl` params (E-RTI-003),
   so `Err(error)` binders have no concrete type -> `enum construction '...Ring': payload type mismatch at 0`.
   Also `async_ref_deliver_wake_i64(self.ring, wake)` cannot infer `Op` (E-MONO-032).
2. `case Ok(nil)` on `Result<T?, E>`: MIR reports "nil sub-pattern requires a declared optional payload slot"
   when the optional's type is not resolved. `case Ok(None)` is NOT a fix: `None` in a payload lowers to a binding with no runtime test. The workaround puts `Ok(Some(..))` first and makes the absent arm `Ok(_)`.
3. `[Future<text>]`: `Future<T>` has field `poll_result: Poll<T>` (type param) so
   `result_err_field_type_key` returns "" -> "array return record element has conflicting or unknown provider field types"
   (src/compiler/50.mir/_MirLoweringExpr/switch_operators_calls.spl:1327, result_err_record_owner.spl).
4. `driver_unit_tldr_imports_v1` matches `Option<CompileResult>` via bare variants without importing
   `CompileResult` -> "missing runtime identity for CompileResult".
5. (Real source bug, fixed at root, not a workaround) `HirExprKind.IntLit(normalized, nil)` in
   src/compiler/20.hir/hir_lowering/_Expressions/expression_components.spl:34: `suffix: text?` must be `None`.

## Workaround sites

- src/compiler/80.driver/driver_build/file_fiber_tldr_bridge_v1.spl: `create` annotated binder; `async_ref_deliver_wake_i64<i64>`;
  `provider_take` / `take_completion_retained` annotated binders (+ `RingSubmission` import); three `Ok(nil)` arms -> `Ok(Some(..))` first, then `Ok(_)`.
- src/compiler/80.driver/driver_build/file_fiber_v1.spl: `FileFiberFutureBoxV1` wrapper for `[Future<text>]`; `Ok(nil)` -> `Ok(_)` after `Ok(Some(..))`.
- src/compiler/80.driver/driver_unit_tldr_imports_v1.spl: import `CompileResult`, qualify `CompileResult.TypeError/ResolveError`.

## Removal condition

Remove the workarounds once the root fixes (generic substitution for static/self-method Result types, nil sub-pattern on
unresolved optional, Future/Poll<T> layout key) are in a stage2 used for bootstrapping. Item 5 is a permanent source fix.

### Design note (fix not attempted: risky, and test runs are on HOLD)
1. Receiver substitution (items 1+2). `MirLowering.rti_enum_match_subject_type`
   (src/compiler/50.mir/_MirLoweringExpr/switch_operators_calls.spl ~2768) calls
   `rti.require_concrete(resolved)` on the method row's term without substituting the
   receiver's class type arguments; `ReturnTypeInterface.receiver_owner`
   (src/compiler/20.hir/return_type_interface_v1.spl ~745) matches `HirTypeKind.Named(sym, _)`
   and drops the args. Fix: return the receiver's `Named(_, args)` from `receiver_owner`, and
   for a method row of a generic owner call `instantiate(row, owner_args ++ method_args)` --
   requires confirming the row's param index order is owner params first, then method params
   (`rti_owner_type_params` + `rti_row_of_function`); a method generic like `then<U>` with no
   explicit args must stay `Param` and keep today's fallback. Item 2 follows: once the subject
   is `Result<Option<i64>, RErr>` the payload slot is a declared optional and `Ok(nil)` lowers.
2. Generic record field element (item 3). `result_err_field_type_key` returns "" for a field
   whose type is a type parameter (`poll_result: Poll<T>`); the array-element owner check
   (switch_operators_calls.spl ~1281) should key the element by the instantiated field type
   (`Fut<text>` -> `Poll<text>`) or treat an erased generic field as uniform.
3. Unimported enum identity (item 4). The bare variants inside `Some(stop)` need the payload
   enum's runtime identity from the callee's declared return type (`CR?`) rather than from the
   consumer's import table.
Each needs its own spec turning the matching `skip` into an `it` before landing.
