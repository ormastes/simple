The retained strict Windows nativeall link contains two rooted missing names, `rt_string_to_byte_array` and `rt_string_from_byte_array`. The two existing C byte facades in runtime_core_io_exports.c use public runtime APIs. The independent audit rejects whole registration of the two broader C provider TUs because other members have caller ABI, UTF-8 policy and cohort compatibility issues; it does not identify a C-private heap crossing in these byte facades. Existing Rust file_ops.rs already owns rt_text_to_bytes and rt_bytes_to_text and the matching RuntimeValue array/string lifecycle, so two typed Rust wrappers provide the narrow owner-coherent repair without importing unrelated provider exports.

Repair adds two unconditional typed no_mangle exports in that Rust owner. Encoding delegates directly to rt_text_to_bytes. Decoding delegates to rt_bytes_to_text, mapping its invalid-input NIL result to rt_string_new(NULL, 0) for the facade's non-optional empty text convention. Existing helper NIL behavior, packed/boxed byte validation, UTF-8 lossy replacement policy, allocation and copy paths remain unchanged.
