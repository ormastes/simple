# GZIP legacy block parser concrete return contract

The actual Phase 3 cycle 6 HIR build rejected `deflate_block_parse` because it returned values without a return annotation. Release f9d07913dcc4ca9623445150c7b8b5e4947610aa still contained that signature. Its success array mixed an integer block kind, boolean final flag, byte array, and integer next offset; a homogeneous array annotation cannot describe those values without erasure.

The parser now returns `DeflateBlockResult?`, with named fields for those four concrete types. Error branches still return nil; stored payloads and fixed/dynamic markers retain their values. The async facade reexports the result type. Existing RFC callers unwrap the optional and inspect named fields, with assertions for all fields and malformed inputs. The old source-text negative-offset test now calls the parser and checks actual failure/success behavior.

At source landing, native/interpreter execution was UNRUN while the independent frozen Phase 3 failure collection remained active. Source review and structural checks were recorded separately. This patch neither modifies that frozen source nor disables Any diagnostics. NLEN validation, reserved-block policy, and other existing erased helpers are outside this bounded return-contract repair.

Normal bootstrap=0, streaming=1, arena=1 and MIR sharding=0 were retained, with 24 jobs, isolated caches, a 600-second guard and 8 MiB log budget.

The produced PE `5ff5259c6b7987f7187f92affd71c39286477548359ee9525e21250718561ac7` exited 0 and emitted `gzip-block-result assertions=8`. Cases cover all fields of stored/fixed/dynamic results and rejection of negative/past-end/empty, short-header and truncated-payload inputs. Input/source pins were reverified after execution. A first run harness failed before PE execution because its outer CC/PATH was missing; the corrected harness executed the original PE without recompilation. The compile's invalid inventory-trace token was a diagnostic-only rejection; it did not prevent the actual build, and no token retry was needed.
