# Uninitialized MC/DC lowering state emits orphan probes

Status: reproduced in two native bootstrap receivers; constructor repair and active-mask guard pending native validation.

The first producer (`8941e4c97af35231e95a7839ae0300cfd828294cf6c1ae72fa141bb3288e2b35`) and the second (`7edb6608bb4bfcb27c64ef417a6649b2cbfffce381b1c5818781b78c56580d88`) crashed in `MirFnVerifier.local_pos`. Both cores identify `compiler.bootstrap_admission.bootstrap_struct_receiver_guard.main`, block 0, instruction 8: `mcdc_static_probe_condition` argument 0 is a live Copy enum with NIL payload (`3`); arguments 1 and 2 hold valid LocalIds 7 and 6.

The first diagnosis suspected the optional `emit_call` result/coalescer. The second producer uses the concrete `emit_call_value` helper and direct assignment, verified in its actual instructions, yet exhibits the identical malformed operand. That disproves the optional boundary as a sufficient diagnosis of this receiver failure. Keep the existing filename for evidence continuity; no general native Option ABI defect is established by these cores.

The second core's complete main MIR contains no begin or end calls, but five condition calls and one mask-range call. Its source path is excluded by the existing default instrumentation policy. `lower_mcdc_decision` therefore correctly bypasses decision instrumentation. However, `MirLowering.new_for_target` omitted all eleven MC/DC state fields. The actual constructor loads NIL (`mov x9,#3` at `0xb19c7c`) and stores it into offsets `0x118` through `0x168`, including active decision ID (`0x148`) and token (`0x160`). `configure_mcdc_mode` sets configuration but does not initialize active state. NIL is not the required inactive ID zero, so the condition-probe guard emits an orphan probe with a NIL token. The mask-range helper also lacked an active-decision guard.

Repair: explicitly initialize every MC/DC field in the sole constructor, with inactive ID zero, typed token LocalId(-1), and empty active-token stack. Require an active decision before emitting mask-range probes. Preserve the existing instrumentation policy, MC/DC begin/condition/mask/end behavior on eligible paths, and actual verifier. The required-result helper is appropriate for begin's known i64 return but did not fix this missing initialization.
