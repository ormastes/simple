# Static generic factories were left without emitted definitions

The bounded public `ErasedCallbacks.injected<T: ReadStore>(store: T)` factory lowers its call to a resolved StaticMethod, but the monomorphization integration pass previously only rewrote generic free-function Calls. The native Cranelift probe therefore emitted the caller without the generic factory or its closure. Linking failed with undefined `app.callback_probe.main.ErasedCallbacks.injected`.

The repair resolves the exact static method symbol and delegates its generic call to the existing `rewrite_call` owner. This preserves the inference rules, unresolved diagnostics, specialization symbol allocation and fixed-point worklist. Ordinary concrete static methods and instance/trait dispatch retain their original forms. No dynamic trait vtable or short-name method fallback is introduced.

Focused acceptance sources are `test/01_unit/compiler/mono/mono_static_generic_factory_spec.spl` and `mono_static_generic_call_contract_spec.spl`. Five real cases passed under immutable Phase 1 producer SHA256 `0f9bfc1f7a9f6aca254755a543687d6b3d60f18b254da9441cb60e1cd3d4a2c7`, executing source revision `16831ca691ec5f31962975bfa5c0912083046ced` plus the owner repair. The cases verify inferred specialization, missing inference diagnostics, actual specialized caller-symbol identity with empty type arguments, conflicting inference diagnostics, and preservation of real ordinary static methods. Peaks were 992,348 and 1,002,096 KiB under a 1 GiB enforced cap.

Harness requirement: source-lowering tests under `SIMPLE_BOOTSTRAP=1` must set `SIMPLE_NATIVE_BUILD_ENTRY_CLOSURE=1`; otherwise non-entry testdata paths intentionally produce empty modules. Initial filtered results are retained as invalid qualification rather than counted as behavioral evidence. Canonical path relocation and removal of diagnostic prints preserve the passing source and assertion semantics; no passing criterion was repeated unchanged.
