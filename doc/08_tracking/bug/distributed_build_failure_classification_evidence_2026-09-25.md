# Distributed build V1 cannot prove deterministic compiler failure

**Status:** Open. **Owner:** distributed build result protocol and parent admission.

`src/app/build/scheduler/worker_execute.spl` formerly converted every nonzero OCI exit to a `success=false` result, while `src/app/build/scheduler/distributed_attempt.spl` recorded every such result as `compiler-failure`. A native exit of 137 can mean OOM or a killed process; even exit 1 can come from a compiler driver whose child crashed. The V1 result wire carries a success Boolean and diagnostic digest but no evidence that the bytes are a deterministic source diagnostic. Treating that Boolean as proof can suppress retry and misclassify infrastructure failures.

The worker now publishes a failed V1 candidate only after an exact durable terminal observation with a known nonzero exit. It writes an empty manifest, bounded diagnostics and a separate versioned failure proof that binds the request, permanent launch binding, fence, native exit, terminal marker digest and exact result wire. Failed outputs are ineligible for acceptance. The parent requires and validates that proof plus exact status replay from the pinned worker, verifies and durably retains the diagnostic bytes, then journals `action-failure-unclassified`. An older worker lacking the new proof cannot satisfy failure SFTP admission. This closes the attempt and frees capacity for bounded retry without claiming source determinism. Unknown exits, provider uncertainty, missing proof, failed status replay and unverified diagnostics keep the fence active for reconciliation. This source change still needs a pure-Simple runtime PASS and live Linux crash/exit qualification.

**Unblock deterministic classification:** Define a versioned, bounded compiler-diagnostic evidence contract bound to the exact action, toolchain, process exit, diagnostic bytes and native container identity. Prove source-failure versus infrastructure-failure classification at the trusted worker, independently validate it at the parent, and journal each classification through the correct ledger transition. Test exits 1, 125, 126, 127, 134, 137, 139, 143 and 255, plus OOM, external kill, diagnostic tampering, compiler child crash and genuine syntax error. Run the end-to-end cases on a current pure-Simple Linux worker. No nonzero exit alone authorizes `compiler-failure`. Older readers reject the new `action-failure-unclassified` journal class, so rollback needs an explicit journal migration or a new owner root.
