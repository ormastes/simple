# BUG-XC-RV32-GCC: riscv32 executable link spawns riscv64-unknown-elf-gcc

- Status: open
- Found: 2026-10-27 (cross-compile matrix lane)
- Spec: riscv_baremetal / riscv_simpleos rv32 exe rows

Evidence binary: C:/dev/p3new/stage2.exe copied to C:/dev/xc/simple_xc.exe (phase-3 stage2, 2026-10-27), Windows 11 x86_64 host, clang/lld 23 (C:/msys64/clang64) + llvm-mingw 20260922 UCRT. Matrix: doc/03_plan/compiler/cross_compile_matrix_plan.md.

## Symptom
`native-build hello.spl --target riscv32-unknown-none-elf` (and riscv32-unknown-simpleos) -> `SimpleOS RV32 stub compilation failed: process spawn failed: riscv64-unknown-elf-gcc: program not found`. GCC is forbidden; also bare-metal none-elf is routed through the SimpleOS RV32 stub.

## Cause / location
link_simpleos_riscv32 in src/compiler/70.backend/backend/llvm_native_link_orchestrator.spl (via is_simpleos_riscv32_link).

## Fix direction
Compile the stub with `clang --target=riscv32-unknown-elf -march=rv32imac -mabi=ilp32` and link with ld.lld; give none-elf its own route (no SimpleOS stub).
