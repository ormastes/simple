text_exists=true

The source now coalesces `env_get_nullable("SIMPLE_PROJECT_ROOT")` to empty
text before path construction. The existing override-before-cwd regression
passes in the subsequent Phase 1 runs. This preserves fallback for an unset or
empty variable and does not hardcode a host path.
