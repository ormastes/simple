# Exec child projection evidence plan

HOST-02 and ORCH-02 require the exact retained child/controller/parent chain,
actual parent WAL row and original execution identity, without another capacity
debit or child-driven release. The ten focused scenarios and expected observable
outcomes are listed in the mirrored authored manual. Every scenario is NOT_RUN.

Allowed validation for this checkpoint is source review, scoped whitespace and
environment/private-import guards. No compiler/build/native tests or campaign
restart. Later qualified runtime must execute the actual journal/reopen specs,
then qualify signed childbegin, installed policy, current reprobe and one-use
delegation independently; historical projection alone cannot satisfy those.
