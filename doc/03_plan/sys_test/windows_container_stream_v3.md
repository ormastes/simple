# Windows stream verification plan

Authored assertions cover pure CPU quantum and request validation, immutable
stream template mutations and exact exec-birth matching. Source-structure
assertions are explicitly source checks, never native behavior evidence.

The Windows-only negative fixture invokes the actual owner on a missing image,
retains and collects the no-child cleanup lease, rejects a forged generation and
rejects raw-to-TTY promotion. All Simple and Windows execution is **NOT_RUN** in
this session; the compiler retry cap is exhausted and no Windows fixture exists.

Required live gates remain successful suspended assignment, actual hard limits,
concurrent handle isolation, backpressure/EOF, cancellation/failure injection,
private Engine endpoint identity, two-stage exec persistence/recovery, shared
API routing and authenticated input/resize. A helper Job receipt must never be
used as container or exec absence evidence.
