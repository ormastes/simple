# Host service domain acceptance plan

Scope: single retained host/container coordinator, HOST-02/ORCH-02, root-selected
owned-native-process effect substrate. All executable evidence **NOT_RUN**.
No compiler, build, seed, native test or extra worker is launched in this lane.

The focused unit SSpec covers actual metadata routing and negative contracts over
existing explicit fixtures. It is not a native generation-lock or gateway oracle.

Required system checks before convergence:

1. Provision a real protected Linux host root and pinned actual provider; require
   owned Ready once. Partial startup must retain canonical cleanup and readiness
   must remain false. Rejected and all cleanup states stay distinct.
2. Send real fresh signed prepare and parent-budget packets through the actual
   persistent domain; drop a response after owner update. A following status must
   preserve real charges and exact current writer. No finite command reopen.
3. Bind kernel peer UID to installed principal/project/scope/actions; reject
   signed identity cross-binding and untrusted wire identity. SDK remains generic.
4. Begin a real bounded wait job, then prove a separately signed control request
   progresses through its reserved queue/slots without waiting for that wait.
   Use actual parent-only begin/create-commit/start-commit cut points and owned
   native child result transport; no fake queued acceptance or thread callback.
5. Sabotage stale job generation, conflicting/late result, truncation, child loss,
   publication failure, close/backpressure and expiry. Preserve facts and charges;
   expiry alone never stops or releases work. Verify deterministic parent commits.
6. Close the exact writer with canonical owned cleanup. Unknown/retained/stale or
   consumed-error stays visible, including nil cleanup. No helper/workload release
   follows merely from service shutdown.

Parent/host owns the missing split phase and initialization interfaces; daemon
owns bounded transport; canonical native/provider owners own actual capabilities.
Do not execute old synchronous native cores on a control callback to satisfy a
scenario. Missing facilities or incomplete routes fail/block rather than skip or
pass. Final independent source review and genuine admitted runtime evidence are
required; no timing, coverage or full-service support is asserted by source scans.
