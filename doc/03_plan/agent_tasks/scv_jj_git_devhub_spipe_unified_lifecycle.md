# Unified lifecycle agent tasks

The detailed stages and ownership lanes are in
`doc/03_plan/app/tools/scv_jj_git_devhub_spipe_unified_lifecycle_plan.md`.

Initial shared-contract owner: primary agent. Sidecars are N/A until lifecycle
IDs, typed operation names, policy schema, manual step phrases, setup/checker
helpers, and fail-fast placeholder convention are stable. Disjoint provider
adapters may then run independently.

Merge owner: primary lifecycle schema maintainer. Final reviewer: independent
best available normal/highest-capability maintainer. Generated-manual reviewer:
the same independent reviewer, not an implementation sidecar.
