## Production test boundary

Use an admitted compiler built from the exact feature source, recorded by executable digest, and a tracked private Git fixture with isolated source/build/cache roots. A compiler built before these source changes cannot qualify the new pipeline by compiling an extracted helper. Keep the latest supported bootstrap toolchain and normal target/profile admission; do not substitute the Rust seed or bypass source-inventory checks.

The fixture must contain two immediate directories, a child boundary, non-ASCII member names, a real generic declaration/use, macro declaration/invocation with target guards, named/ordinary aspect declarations supported by the current grammar, and globals requiring dynamic initialization. Include a separately proven no-initializer module. Record exact source inventory, target/config policy, executing compiler image, each physical file TLDR, PackageInit bytes, emitted objects, typed link startup order and final executable SHA.

1. Cold full compile: no PackageInit exists. Prove rebuild/full-visit, complete fresh producer publication only after successful object/link observation, and real executable result/initializer order. Missing category coverage must leave PackageInit unavailable, never substitute an empty root.
2. Unchanged rebuild: decode the published version through the actual admitted stage2 reader. Compare full canonical bytes and woven executable behavior. Retained link receipts cannot fabricate fresh startup authority.
3. Mutations: change a generic signature/default/body separately, macro input and guard, local aspect interface, ancestor aspect, member addition/deletion, and initializer order. Assert the appropriate roots/consumer slices change and no stale source object is reused. Measure unchanged-output child cutoff separately.
4. Corruption/failure: truncate/corrupt inline facts and physical envelopes, remove a file TLDR, alter producer/target/policy, inject atomic-publish failure, and reject a mismatched object digest. Assert quarantine/rebuild/full visit with a correct executable or explicit failure, never silent admission.
5. Concurrent consumers: overlap two requests for one directory generation, retain an old reader across publication, then release it. Prove one producer, immutable snapshots and bounded ownership. Exercise plugin allowlist rejection before loading code.
6. Resource evidence: report first-directory check and first-object wall time, job/chunk selection, process-tree RSS, object counts and all omitted/unsupported capabilities. A timeout or unavailable target is not a pass.

Add real assertions there as each actual producer and consumer becomes runnable; do not convert fail-fast placeholders into skips or constant passes.
