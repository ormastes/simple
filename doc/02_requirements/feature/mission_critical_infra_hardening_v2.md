# Mission-Critical Infrastructure Hardening V2 — Feature Requirements

Status: selected 2026-08-11 (`C1 + O1 + R2 + M2`)

- **REQ-MCI-001 — Exact-current compiler admission:** Release admission requires an exact-current pure-Simple compiler identity and provenance receipt. The gate must execute discriminating emitted artifacts and fail on Rust-seed, hybrid, stale, unknown, missing-function, or non-executable output.
- **REQ-MCI-002 — Unified tooling evidence:** Compiler, library, MCP, LSP, bootstrap-essential-tool, lint, duplication, whole-test, startup/latency/RSS, runtime-contract, and direct-env checks must be represented by one fail-closed admission result with bounded execution and artifact identities.
- **REQ-MCI-003 — Certified SimpleOS manifest:** A versioned manifest names the host/guest configurations certified for a release. Every selected row and receipt must bind the canonical host and guest identities while proving boot, mount, target-side listing, arbitrary filesystem-program execution, compiler lineage, source identity, and run correlation. Unselected 24-cell rows remain visible and cannot support an umbrella all-platform claim.
- **REQ-MCI-004 — SimpleOS compiler payload:** Certified guest images contain and execute the required compiler/interpreter/loader payload from the guest filesystem, including the canonical `/usr/bin`, `/bin`, `/sys/apps`, and `/SYS/SIMPLETOOL.SDN` placements.
- **REQ-MCI-005 — Packed DrawIR-v3 ownership:** GUI and Web producers lower through canonical semantic/layout owners into `DrawIrComposition`; Engine2D consumes it. DrawIR-v3 uses a count-plan-admit packed generation arena and fixed queue/ring capacities. Active generations never grow, truncate, clamp, or silently fall back.
- **REQ-MCI-006 — Rendering provenance:** Rendering PASS requires typed overflow/rejection receipts, generation identity, real backend/device provenance, structured interaction evidence for HTML-backed UI, exact CPU/device readback where claimed, and valid RenderDoc artifacts where required. Transient font atlas/cache material remains outside Draw IR.
- **REQ-MCI-007 — RelaxedAllocationProfileV1:** The strict default forbids post-ready dynamic allocation in declared critical contexts. The selected relaxed profile permits only preallocated, sealed, per-domain arenas outside kernel, ISR, storage-commit, ownership-publication, and other declared critical contexts.
- **REQ-MCI-008 — Allocation failure safety:** Each arena has a hard quota and generation, reports high-water/overflow telemetry, returns typed exhaustion without partial publication, and supports deterministic rollback. Exhaustion cannot corrupt another domain, change committed storage, bypass isolation, or trigger an unbounded fallback. Its sealed profile identity is SHA-256 of a version-tagged, fixed-order, length-framed canonical serialization; every injectable boundary has a stable ID/name in an enumerable registry and a ledger row with before/after subject and isolated-domain committed-state hashes.
- **REQ-MCI-009 — Concurrency/process safety:** Parallel work uses bounded runtime-pool evidence, bounded subprocess capture, deterministic cancellation/timeout, fixed queue/in-flight admission, and `pid <= 0` rejection for every kill/wait path. Relaxed atomics are outside this selected allocation feature unless separately approved and proven.
- **REQ-MCI-010 — Fail-closed aggregate:** Stale reports, unavailable prerequisites, external-host gaps, skipped checks, unknown identities, synthetic handles, screenshots without interaction/provenance, source-only inspection, or cached artifacts keep the applicable claim blocked.
- **REQ-MCI-011 — Traceability and knowledge:** Every requirement maps to executable non-placeholder SSpec evidence and a readable generated/manual operator flow. Affected research, architecture, design, plan, guide, report, feature-expert, layer-expert, workflow, and bug-tracking documents remain current.
