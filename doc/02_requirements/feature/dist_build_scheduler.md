# Distributed build and fast feedback: feature requirements

**Selection:** The user requested full implementation of distributed builds, faster local and GitHub feedback, CI, submodule/branch policy, the extracted Clang cache report scope, and parallel Astra-reviewed delivery. This selects the complete functional end state and parallel work lanes. The user selected N2 numerical targets on 2026-09-26; see [the final NFR](../nfr/dist_build_scheduler.md). Selection does not establish measured compliance.

**Implementation constraint:** Implement scheduler decisions, protocols, recovery, policy and provider composition in Simple `.spl` modules. Reuse existing Simple host and OCI interfaces. Add C only for a small platform operation that cannot be expressed through an existing Simple or canonical SFFI interface; keep the foreign ABI in its owning runtime module and justify each new boundary during verification. No C scheduler or policy engine is authorized by this requirement.

|---|---|---|
