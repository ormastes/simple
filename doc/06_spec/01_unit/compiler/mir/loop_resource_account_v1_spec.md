# Shared loop resource account

Seven authored actual API scenarios, all UNRUN. Tests freeze before account implementation.

- Exact fixed 20-field construction boundary.
- Inclusive multi-category reservation and exact exhaustion.
- Atomic rejection on the final category.
- Negative, inconsistent and overflow-sized reservations.
- Shared class alias and terminal close.
- Invalid hard limits.
- Fixed observation copies and stage update.

This establishes intended logical account behavior only when executed; it does not establish consumer allocation placement, native allocation/RSS, class privacy or full-route memory qualification. Legacy rich-ledger factory remains a separate compatibility API.
