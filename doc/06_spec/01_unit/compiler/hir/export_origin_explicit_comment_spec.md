# Explicit export-use comment origins

Authored manual for [the executable specification](../../../../../test/01_unit/compiler/hir/export_origin_explicit_comment_spec.spl). This is not claimed to be generated by `spipe-docgen`.

The generated-comment hint scanner must leave explicit `export use` declarations to the parsed import representation. A stale `# Re-exported from ...` marker must not manufacture a sibling owner, and consuming an explicit declaration must clear that marker before subsequent bare exports.

## Setup and production path

`comment_origin_surface` parses each supplied body with the actual `parse_and_build_module_scoped` bridge, asserts that the current parser has no errors, and calls `module_surface_from_owner`. The bridge does not restore a disk-keyed frontend cache. Each body retains the runtime facade's logical provenance. The final scenario reads the actual patched facade file rather than substituting a model.

## Scenarios

1. **Multi-item explicit export.** Parse the sweeper's three-name export after a generated owner comment. Require an empty generated-origin index and a nonempty parsed export surface.
2. **Multiline explicit export.** Parse brace-delimited names on separate lines, followed by an ordinary comment and a bare export. Require no generated origins.
3. **Marker consumption.** Parse a single-symbol explicit export followed by another bare declaration. Require the earlier marker not to leak into the later declaration.
4. **Keyword boundaries.** Parse extra spaces and a tab after `use`; require no hints. Parse the ordinary name `uses`; require its legacy source name to remain `uses`.
5. **Explicit alias.** Parse `original_value as public_value` inside an explicit import. Require no fabricated generated hint and a nonempty export surface. This scenario does not assert the exact alias-to-symbol binding.
6. **Legacy bare exports.** Keep a generated owner across an ordinary comment, then export two names. Require exactly two origins with the expected sibling owner/source names; a later unmarked bare export must not inherit them.
7. **Missing owner.** Publish the parsed surface into the real `ModuleSurfaceBuilder`, then query `hir_export_origin_surface_index`. Require `-1` for the nonexistent generated owner. This does not execute the complete `register_imported_symbol` error path.
8. **Actual runtime facade.** Read and parse the patched runtime facade. Require a nonempty export surface and no generated phantom-owner hints.
