The effectful owner uses the admitted nm route on every input and requires exactly one definition. A nonobject fixture must fail inspection.

The opt-in generated entry calls the strong int64 consumer only after runtime and discovered module initialization. Native control and the one-shot thread-owned creation window surround the handoff; the Simple consumer reacquires control through the normal facade. Every returning failure seals the window and prevents user main. The symbol and request flag grant no profile authority. An nm text definition does not prove the scalar function ABI; the actual source export and native qualification must supply that evidence. Missing real qualification remains a startup refusal, not a successful capture.
