# Stage4 split native linker source contracts

Mirror of `test/01_unit/compiler/backend/stage4_native_link_source_contract_spec.spl`.

The executable SSpec verifies canonical native-all archive discovery, deterministic compiler-backfill capsule construction and transaction ownership, provider inventory before projection, dedicated dynamic-loader archive validation, and portable resolver selection for symbol scans, archiving, section reading, and object copying.

This is static source and build-policy evidence. It does not perform the complete Stage4 native link across every supported operating system and toolchain.
