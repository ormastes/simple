# Managed parser transport contracts

AUTHORED_UNRUN. REQ-MANAGED-PARSE-WIRE-001 covers canonical bounded codecs; REQ-MANAGED-PARSE-AUTHORITY-002 covers cross-record authority checks. The executable companion calls the actual encoders, decoders and validators. It tests a nested run round trip; cache stability on worker replacement and invalidation on source/target changes; duplicate/path refusal; result round trips and lease/membership/source refusal; failure details and contradictory statuses; malformed wire refusal; and run identity/resource controls. No test parses a source file or establishes process admission.

This is a new explicit `SIMPLE-MANAGED-PARSE-*-1` protocol, not recovered compatibility with an older absent implementation. Scalars use the existing BuilderWireReaderV1 percent escaping. Snapshot and module-result nested scalars are limited to 65536 bytes; complete envelopes to 16 MiB; inventories to 4096; run slots to 64. Collections preserve authored order and decoders require exact re-encoding. Snapshot digest covers producer, cache identity, OS/arch/CPU, byte bound and ordered module/source inventory; it excludes slot/generation so a reaped replacement can reuse content. Actions/results bind those excluded identities and the exact lease separately. Successful results require canonical content-addressed blob paths and no diagnostics; failed results require diagnostics and no reusable blob. Parent source/blob rereads remain mandatory.

Run envelopes embed the existing persisted-graph codec. Schedule and profile owners expose no codecs; their fields are encoded explicitly, using the real SCC identity and profile validator. SCC wave coverage, dependency order and graph-edge bindings are checked. The adapter owner confirmed its existing common binding/lease/reap API is compatible and imports none of these transport records.

Each graph action must use `managed-reference-parse-v1:<worker digest>`. Its input digests must equal the unique content-digest dependency set of the selected SCC modules, matching the existing graph owner's uniqueness contract. The snapshot digest separately preserves exact module identities, paths, order and multiplicity: two distinct modules may contain identical bytes and therefore share one graph dependency. Rehashing an unrelated graph does not satisfy these associations. Additional scenarios independently alter commands and inputs while recomputing the graph digest, round-trip two same-digest modules, and reject missing or extra dependencies. Profile scalars and pool elements also obey the underlying wire scalar bounds; a 65,536-character profile name round-trips while overflow and NUL values are refused before encoding. Escaped CR is valid wire data and round-trips through the shared scalar codec.

Missing parser worker `compiler.driver.managed_parse_group` and qualification owner `driver_build.managed_parse_qualification` remain separate actual dependencies. No placeholders were added. Compiler, unit, native worker, recovery, and end-to-end execution remain UNRUN. Static acceptance cannot establish parser results, runtime authority, or grouped-parent success.
