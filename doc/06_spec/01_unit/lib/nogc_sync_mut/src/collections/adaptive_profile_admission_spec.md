An attributed container receives a sample bound to one declaration site and target. The container validates that binding and the measured counts before the source attribute chooses its physical storage. Explicit `linear` stays linear after a valid hot sample; `auto` may start in hash storage from the same sample.

## Admit a valid forced choice

1. Prepare a valid hot sample for `ast://profile/admission#stable` on `x86_64-v3`.
2. Construct attributed text set/map and generic set/map instances with `linear`.
3. Check that every instance uses linear storage and retains inserted membership or values.

## Apply an admitted auto choice

1. Construct an attributed text set and generic map with `auto` and the same sample.
2. Check that both instances select hash storage before insertion.

## Reject stale or malformed feedback

1. Change the expected site or target and check admission fails.
2. Reject empty identity, an impossible single-sample hit/miss count, zero samples, and an incomplete or contradictory hash probe/collision pair.
3. Accept independent p95 hit and miss marginals across multiple samples without requiring their sum to equal the p95 lookup marginal.
