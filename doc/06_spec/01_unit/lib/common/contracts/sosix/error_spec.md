## Scenarios

### SOSIX typed error vocabulary

#### maps the three typed kernel statuses and keeps the rest native

- Map EAGAIN-shaped slot exhaustion to queue-full
   - Expected: full.kind equals `SOSIX_ERROR_QUEUE_FULL`
   - Expected: full.native_code equals `-11`
- Map timeout and cancellation statuses
   - Expected: sosix_error_from_status(SOSIX_STATUS_TIMED_OUT, SOSIX_NATIVE_DOMAIN_SIMPLEOS, 3).kind equals `SOSIX_ERROR_TIMED_OUT`
   - Expected: sosix_error_from_status(SOSIX_STATUS_CANCELED, SOSIX_NATIVE_DOMAIN_SIMPLEOS, 0).kind equals `SOSIX_ERROR_CANCELED`
- Keep an unmapped VFS failure native and carry its code and progress
   - Expected: io.kind equals `SOSIX_ERROR_NATIVE`
   - Expected: io.native_code equals `-5`
   - Expected: io.transferred equals `12`

# @req REQ-SOSIX-ERR
step("Map EAGAIN-shaped slot exhaustion to queue-full")

expect(sosix_error_from_status(SOSIX_STATUS_CANCELED, SOSIX_NATIVE_DOMAIN_SIMPLEOS, 0).kind).to_equal(SOSIX_ERROR_CANCELED)
step("Keep an unmapped VFS failure native and carry its code and progress")
val io = sosix_error_from_status(-5, SOSIX_NATIVE_DOMAIN_SIMPLEOS, 12)
expect(io.kind).to_equal(SOSIX_ERROR_NATIVE)
expect(io.native_code).to_equal(-5)
expect(io.transferred).to_equal(12)
