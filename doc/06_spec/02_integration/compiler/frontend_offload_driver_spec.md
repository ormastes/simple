## Purpose and Audience

Runs a hello world through the binary named by `SIMPLE_BIN` (default
`/home/yoon/dev/simple/bin/simple`). The default path must stay unchanged. The
two switch cases are only observable through the pure-Simple driver; the
deployed `bin/simple` is the Rust seed, which ignores the switch, so they are
skipped unless `SIMPLE_BIN` names a self-hosted binary.
