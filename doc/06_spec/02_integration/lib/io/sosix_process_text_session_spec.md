# Explicit process text session manual

Authored companion to `test/02_integration/lib/io/sosix_process_text_session_spec.spl`.
Status: **UNRUN**; this manual was not generated by an executed runner.

Run only with an admitted Linux native V3 provider. The scenarios invoke actual
shell/cat children, never a mocked process or a text-sentinel capture API.

1. Capture UTF-16LE stdout and UTF-16BE stderr one byte at a time; require exact
   internal bytes `[65,0,240,159,152,128]` in both streams.
2. Encode BOM-prefixed UTF-16BE stdin through cat; require the same internal bytes
   and native accepted/written counts of ten.
3. Require a BOM, receive none, inspect the typed stream error, then cancel and collect.
4. Reject invalid UTF-8 while retaining the child owner for collection.
5. Finish a one-byte UTF-16 stream only at native terminal drain and reject truncation.
6. Exceed a four-byte native capture bound and require typed truncation.
7. Preserve actual provider deadline flags through polling and collection.
8. Collect through one alias and require all aliases to reject reuse.
9. Reject NUL argv before a real child can create its witness file.
10. Reject invalid profile metadata before spawn.
11. Reject invalid timeout/capture limits before spawn.
12. Reject invalid poll arguments without consuming the valid owner's output.
13. Observe early child stdin close and distinguish accepted from written bytes.
14. Retire unread retained output after a sticky decoding failure.

The separate native fixture checks binary stdin/NUL/non-BMP/BOM/carry, delivery
receipts, alias retirement, malformed output and cancellation. Runtime ABI,
RSS/performance and cleanup under injected native failure remain unqualified.
