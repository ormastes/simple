# Honest SimpleOS server protocol discovery

The operator starts the canonical HTTP owner and retains its loopback and
worker-dispatch identities. Cleartext startup contains only TCP HTTP/1.1; TLS
facts come from loaded TLS 1.2/AES configuration, and HTTP/2 appears only after
an actual worker negotiation receipt. Offers for HTTP/3, QUIC, WebTransport, WebSocket ALPN, and
unknown identifiers are rejected.

For secure shell, bind the canonical SSH listener with configured public-key
and host-key owners. SSH is reported only after live authentication and channel
admission. A live accepted SFTP subsystem request is not enough to publish SFTP
while its per-principal atomic VFS capability is absent. The publisher consumes one generation-bound handle; stale and
replayed handles fail. No client SFFI extern or framing-only module is proof.
