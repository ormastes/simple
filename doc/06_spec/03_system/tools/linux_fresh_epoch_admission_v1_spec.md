# Actual Linux fresh epoch admission and profiled creator

Status: **AUTHORED_NOT_RUN**. Source:
`test/03_system/tools/linux_fresh_epoch_admission_v1_spec.spl`.
This spec requires a disposable administrator-provisioned profile B and a real
provider/broker installation; it performs no provisioning or synthetic preseed.

| Requirement | Actual scenario assertion when executed |
|---|---|
| REQ-LINUX-FRESH-EPOCH-001 | The zero-argument factory returns genuine installed custody bound to a verified actual first machine charge under its original writer. |
| REQ-LINUX-FRESH-EPOCH-002 | The actual profiled provider starts once; a copied admission refuses a second startup and the original owned provider remains current. |
| REQ-LINUX-FRESH-EPOCH-003 | After exact actual process/writer/custody cleanup, reopening the same machine storage observes the original four-row charge and its two-row unknown creator child revision. |

Set `SIMPLE_LINUX_FRESH_EPOCH_TEMPLATE` to an administrator-prepared bounded
normalized stream-template file. It is unsigned data, not authority: installed
successor binding and restrictive validation determine every effect-bearing
program, broker, environment, input, cgroup and resource field. The actual root
installed profile/policy, dedicated UID, native store/cgroup/endpoint and
compiled broker must separately exist. Initial publication must meet the
lower same-writer fresh-binding eligibility; the spec never repairs or clears
an old or ambiguous machine ledger.

Every actual admission, process, storage or cleanup output is retained before
assertions. Pending startup/cleanup fails the scenario and preserves those
owners. A failed actual close stops before reopening storage. The final storage
open occurs only after provider cleanup, and reads the existing namespace
without creating another journal or a grant.

The `Started` owner denotes an actual profiled process, not an authenticated
endpoint, workload cgroup, remote client or workload reservation. This single
scenario does not cover populated-store restart, native CAS/fork/fault
injection, device grants, quotas or transport authentication. No skip or mocked
provider supplies passing evidence; none of these assertions has been run.
