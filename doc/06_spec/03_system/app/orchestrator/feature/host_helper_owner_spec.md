The fixture uses real Ed25519 signatures, indexed role/scope keys, filesystem objects and the existing capacity journal. Parent setup is explicitly a trusted capacity primitive; these tests do not claim a complete signed controller dispatch, native parent workload, native helper effect or end-to-end helper service. No provider is mocked into success and no native launch result is synthesized.

The unchanged `HostHelperRequestV1` type is owned by the new codec module and re-exported by the helper owner. APIs: `host_helper_request_encode_v1`, `host_helper_request_decode_v1`, `host_helper_request_store_v1(root,request)`, `host_helper_request_load_v1(root,operation_id)`. Encoding delegates helper plans, budget proofs, operations, grants, approvals and assignment references to existing owners. Decoding reconstructs the parent binding via `controller_assignment_decode_reference_v1` and `controller_assignment_restore_v1`; it creates no authority and contains no lease decoder.

Trusted-owner storage root only: content-addressed canonical packets live under `host-helper-request-packets/<sha256(packet)>.sdn`; immutable operation references under `host-helper-requests/<sha256(operation_id)>.sdn`. References bind exact operation ID and packet digest. Load verifies canonical reference, packet hash, full request decode and exact requested operation ID. Exclusive publication, private mode0600, bounded no-follow readback and file/directory/root synchronization guard immutable objects. The existing operation reference is checked before publishing another packet; conflicting, partial or symlink entries never authorize replacement. An orphan packet from an interrupted publication is not admission or lease authority. Load success never replaces current proof/context validation.

The explicit begin replay guard uses the exact original helper reservation operation before parent/sibling/object IO and before begin. Executing/unknown work never receives a replacement lease. Helper duration cannot exceed its signed budget operation duration. Aggregate accounting remains one physical ledger and includes parent plus every retained nonreleased sibling, including uncertain states and renewed proof attempts.
