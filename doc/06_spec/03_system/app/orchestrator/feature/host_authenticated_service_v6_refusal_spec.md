# Explicit authenticated Host command refusals

AUTHORED_NOT_RUN. Four cases call the actual command dispatcher or production
shape validator. They cover missing inputs, the distinct legacy command name,
an unsupported installed backend, and extra inputs. Each invoked command must
fail before creating native owners; returned recovery remains absent.

This is early refusal coverage only. It does not establish successful installed
Host startup, OS entropy, protected setup publication, listener authentication,
exact-operation dispatch, restart, cleanup, or interactive terminal support.
Those require the genuine configured Windows fixture and remain NOT_RUN.

A fifth actual-dispatcher scenario refuses missing or extra `host-auth-setup` arguments before any protected-root or entropy operation. The setup command has no caller-secret or legacy-conversion option. This is AUTHORED_NOT_RUN and does not qualify real setup publication.
