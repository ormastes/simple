# Layout Framework Architecture — TLDR

- Pure-Simple `common.structural` capsule; browser layout remains the oracle consumer.
- Reuse one serial CPU adapter; do not copy profile algorithms.
- SCC-condensed deterministic waves; bounded cycles or explicit fault.
- GPU only for cost-winning homogeneous block/flex/grid batches.
- Inline always crosses `TextMeasurePort`; no shaping approximation.
