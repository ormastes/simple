# Source-to-HIR custody

The public archive and registration APIs are mechanical consumers. A valid
source SHA, provider receipt and codec checksum cannot prove that an editable
HIR body was actually lowered from that source. The reviewed counterexample
changes a function tail or field default while preserving source claims,
types, symbols and the physical source SHA, then publishes a self-consistent
archive/journal. Claim reparse and downstream layout gates do not detect that
different executable body.

The actual archived shard transaction now obtains its lowerer from a private
controller factory. A caller-provided lowerer is ignored for archive mode.
The factory replays the exact admitted source rows through bounded no-follow
physical reads, coverage-selected content equality, the selected forced-source
frontend and the existing per-file surface projection. Logical aliases retain
the actual source order and builder identity rules. The compact result feeds
only the private lowerer; it is never installed into the public driver surface
field. Later transactions reuse that private owner under the same selected
source, schedule, closure, provider and frontend context.

Both private/shared flat AST restores and HIR cache restores are excluded from
this custody producer. Existing retained/default callers keep their cache
behavior. The frontend dependency preserves actual target-cfg/advisory
preprocessing, domain extraction, parser and desugaring without changing
ambient environment settings. The transaction requires the supplied logical
source label to match its actual source-index row. After genuine lowering,
archive input binds the actual `HirModule.name`; it never renames the module
to a logical label. The private custody frame records both names separately.

The controller alone can prepare custody, and only after real parse/lower,
archive publication and compact registration capture. Preparation is private;
the sole exported predicate cannot issue or replace records. A body-free
descriptor is promoted while the real scope is paused. Installation occurs
after ownership, reverse-reference, diagnostics and scope-close gates succeed.
The private lookup binds actual driver reference word, private issued serial,
source index, complete artifact/body/warnings identities, source/authored path,
producer/runtime selection, frozen schedule/closure, semantic policy and
selected frontend/target-cfg decision receipts. A public constructor or a
recomputed digest cannot populate this lookup.

The native class-reference cast uses the existing actual MIR/LLVM pointer to
integer path. Native identity controls are required; static inspection does
not qualify its execution. Full-context checks prevent an unrelated context
from authenticating through an address reused with a different source/body.
The lookup holds no `CompilerDriver` or `CompileContext` reference.

The retained private lowerer holds the existing frozen declaration owner and
the existing 49 scalar/text/index phase memo roots. Before closing each body
scope, `begin_module` resets symbol tables, resolver, aliases, full impl
functions, lowered/imported traits, imported enums and local inference maps.
The archive branch additionally clears `prescan_type_parameters` and
`declared_pattern_enum_slots`, which are omitted from both that existing reset
and phase-memo promotion; the trait count mirror is reset as well. No whole
lowerer or complete module is promoted. The target-cfg receipt is explicitly
promoted before closing its actual selected parse lease.

The surface owner is not entirely body-free: the existing projection retains
trait default `ParserFunction` bodies for cross-module impl injection and enum
struct-variant default expressions. It omits ordinary executable function
bodies, ordinary parameter/field defaults and constant values. Whole
`ParserModule` and `HirModule` owners do not escape surface replay. The four
claim registries are snapshotted, reset to fresh containers, and restored on
every Result edge so replay cannot overwrite the original containers or add
another set of advice. Future bounded default-body leasing must preserve these
exceptions rather than delete their semantics.

This repair performs one additional full declaration parse per actual driver
until the original phase-2 producer supplies the same private custody. Its
time, retained declaration/default bytes and peak RSS are unmeasured. Native
controls belong to the genuine weave fixture: real producer positive reads,
modified full bodies/defaults, forged caches, distinct drivers with otherwise
equal metadata, caller lowerer substitution and inactive/paused refusal. No
native jobs were run for this patch. The downstream weave owner must invoke
the private custody predicate before accepting original archives; cold,
quiet/current, final private pin and MIR production integration remain required.
