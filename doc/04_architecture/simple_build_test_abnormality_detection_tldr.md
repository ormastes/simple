# Build/Test Abnormality Detection Architecture — TLDR

One layered pipeline turns platform-owned scope receipts into handle-free evidence, stable identities, independent budget decisions, and explicitly approved baseline comparisons.

## Core Shape

- Platform providers enforce and observe; `execution_metrics.spl` classifies and compares pure values.
- Build/test adapters emit stable subjects separately from volatile runs, spans, counters, resources, and artifact digests.
- `test_runner_metrics.spl` owns class/cohort identity across all runner modes.
- Exact-tree claims require cgroup/provider evidence; fallback quality never upgrades itself.
