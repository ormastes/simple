# Actual archived HIR production controller

The controller owns the real streaming, nonshard source visit loop and a private per-driver compilation generation. It obtains the selected managed provider from the driver, captures the frozen schedule, invokes the closed forced-source HIR producer for each physical visit, and publishes logical aliases through the actual journal. Poisoned first visits preserve status-2 continuation and prevent alias retries. It retains compact publication owners rather than reconstructing ctx.hir_modules.

Phase 3 issues the genuinely replayed weave boundary. Phase 4 invokes the actual current/cold/quiet, configured collection, root/FIFO or unchanged zero-template, immutable verification, and mono/post-mono publication factory. The production failure API distinguishes unpublished diagnostics from failures minted immediately at actual diagnostic publication; the controller adds no extra generic error after the latter. The existing final capture wrapper retains its original diagnostic-array API.

Begin runs at a closed compilation boundary. It revokes previous private source/final pins, resets compilation publication fields, and clears the legacy cache-warning alias after its diagnostics have been replayed. Previously recorded ctx warnings remain. Foreign active or paused leases are refused without persistent diagnostic mutation. Finish revokes publication and leaves a tombstone, so an incomplete or revoked producer cannot silently select the retained route. The borrowed optional repository getter returns None only for no producer or an untouched new generation.

The final specialization selection reader validates the actual final private pin before reading immutable captured specialization selections. This supplies complete-function identity and provenance for MIR's later specialization output union; a mangled function name is not origin authority.

Validation is source-only. The production fixture has 19 guarded checks, including real source/provider production, aliases, occupied leases, real warned-cache reuse, revocation, actual recursive specialization errors, and post-mono policy diagnostic counts. The final repository fixture has 43 checks including specialization selections against complete final function records. Both are native UNRUN. This change does not establish production activation, compiler admission, completed-HIR memory reclamation across all downstream consumers, or improved full-CLI RSS. Root orchestration and the actual MIR consumer must be integrated and qualified with the admitted producer.
