# Genuine current-to-final archive consumer

Status: source implementation and native fixture authored; native qualification
is pending an admitted new producer. This does not activate the bounded driver
route, evict previously promoted HIR, establish a full CLI RSS repair, or prove
the unchanged 8 MiB raw-envelope limit covers the largest admitted module.

`hir_mono_final_repository_v1` has one issuing factory. It invokes the real
weave/cold/quiet/current factory and configured collection controller internally.
It accepts no caller current bodies, cold DTO, candidate report, cleanliness
boolean or recomputed admission hash. Before consuming current registration it
checks that factory's private pin and full sealed state. The no-template branch
archives unchanged complete current bodies; it never rewrites roots, prunes
templates, allocates symbols or invents completed execution receipts. Every
body lease rederives the exact repository/state/schedule current-seal formula,
so a valid public same-parent default-99 artifact cannot replace sealed input.

The generic branch runs the actual ordered roots and growing FIFO. It publishes
real warnings/statistics and the existing E-MONO-033 diagnostics before capturing
and replaying the actual applied ledger. Both branches run the shared aggregate
closure-index-before-walk verifier and existing post-mono policy publisher. A
final closed genuine semantic/weave replay checks actual source, gates, policy,
transforms and inventory before private final issuance. Explicit ambient mono
skip remains on the retained route: this verified factory refuses that request
rather than issuing a report-qualified read pin for unverified skipped work.

Final metadata keeps three distinct schedules: alias-inclusive logical mono
order, genuine layout/source declaration labels, and actual source-index MIR
emission rows. Normal native emission uses the existing admitted physical-owner
helper; full-inventory/cold rows retain logical emission names. A query-1 matcher
rederives actual active source rows and route flags, checks configured collection
recipe/result metadata, verifies the original private source/policy/cold context
pin after mutable mono state is consumed, then compares immutable final bytes
with the privately registered expected SHA and serial. No global diagnostic
total is pinned because later MIR publication legitimately changes it.

The borrowed reader performs no begin/pause/end or full source replay. It loads
the actual captured execution-selected complete body, or the unchanged no-template
body, and requires the exact verified full HIR digest, physical name/path and
symbol counter. Mutable public repository fields or resealed unknown keys cannot
install entries in the same-module private issuance map. The repository retains
compact declaration/state and receipt metadata, not a HirModule or CompilerDriver.

`hir_mono_final_repository/main.spl` contains 41 native guards using actual selected
source/provider setup. It compares both logical aliases' complete HIR digests and
actual report with retained mono for zero-template and cross-template specialization
branches; checks unchanged zero state, active physical-source scheduling, foreign
driver rejection, public report reseals, valid public stored final/default changes,
stale current seal, source receipt and active source-row mutations, collection
mode, emitted owner, occupied/paused leases and post-close churn. The launcher
selects `final-repository` and includes the existing actual managed tool/runtime
admission and before/after source/provider snapshot gates. All 41 are UNRUN.

Remaining production integration must replace resident aggregate ownership at
the actual driver publication seam, wire the issued reader into MIR declaration,
prescan and body consumers, preserve phase receipts/diagnostic ordering, and
measure the exact full inventory with the existing cap. Source-only acceptance
of this consumer is not completion of those requirements.
