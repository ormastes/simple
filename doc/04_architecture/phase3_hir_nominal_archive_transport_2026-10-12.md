# Archived mono nominal transport compatibility

Incoming release17c1347 retains nominal owner identity across caller/template namespaces. Its shared pass now relocates type arguments and callable result stamps through actual symbol tables. The archived consumer previously omitted those tables and assumed exactly one global symbol allocation per request. Valid nominal calls would consequently fail E-MONO041/042; template-local request arguments also cannot be replayed in the caller namespace.

Actual source-current registration captures a body-free encoded projection of declaration/value symbol rows (including their exact types/spans), qualified type lookup, structural union occupied IDs, current scope ID and allocation counter. It contains no lexical scopes, AST, function bodies or live SymbolTable handles. Scratch consumers reconstruct tables and share a handle only for the exact original archive plus complete current body cohort. Incoming shared nominal identity/relocation remains the implementation, including distinct local IDs, owner/kind checks and counter reservations.

Per-function publication retains only added nominal rows/qualified index bindings and the counter in an append-only patch, not another complete provider projection. Actual independent complete-body rewrite replay verifies the full delta, requested caller arguments, template-local arguments, caller result stamps, diagnostics, six counters and output bytes before state mutation. Original projections and row patches are sealed in state and immutable v4 verification recipes. Final assembly applies those patches to the complete original body's genuine symbol table before specialization symbols, preserving its lexical scopes/indexes and shared alias rows. Actual execution's private expected-state pin is issued at construction and after successful applied publication, so edited compact declarations cannot be captured by merely retaining an old epoch/ledger.

The new nominal-mono native fixture has eight guarded groups. It parses/lowers real caller/provider sources with actual module surfaces, exercises caller Local through a generic identity and scalar instantiation returning provider Box, plus two logical aliases of the same physical provider. It compares complete final HIR bytes, symbol counters, all six mono statistics, ordered diagnostics/warnings and actual post-mono reports against the retained pass; checks real transported rows/caller provenance and refuses edited published patches. This fixture and all retained controls are native UNRUN. The typed current frame in this fixture is mechanical and grants no production source/final admission.

No full-CLI RSS or timing improvement is established. Initial declaration bytes remain resident; per-body scratch reconstruction and independent replay add unmeasured work. The next admitted producer must qualify actual native parity and the full inventory/cap route. The root owns all native jobs and production activation.
