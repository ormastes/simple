# Windows primary geometry architecture

The existing generic V5 service owns the issuer and canonical Host domain. The pane owns the sole terminal session. A Host geometry task borrows both and retains only its separate exchange, immutable-attempt cursor and exact writer correlation. The common terminal geometry V2 facade dispatches the existing Linux owner or Windows provider owner; platform HTTP/native details remain below that facade.

The Windows leaf reuses the read-only Engine probe and actual native controlled pipe API. Input remains bound to the attach connection. Geometry uses a separate connection with Geometry kind and an exact HTTP-payload binding. The native boundary validates the actual deadline and one-write sequence; upper layers preserve durable request identity and uncertainty.

Attempt and terminal records are immutable children of the existing journal. No capacity state machine, second ledger, mutable global pointer, native export or native whitelist extension is introduced. A crash cannot turn missing outcome evidence into permission to replay. Source contracts are implemented; all runtime/performance qualification is pending.
