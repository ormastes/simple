# Mission-Critical Infrastructure Hardening V2 — TLDR

The release matrix is evidence-first: common contracts define identities,
compiler/MIR produces canonical semantics, tools collect proof receipts, and
the V2 app gate materializes signed delivery evidence.

AC-6 is an explicit capsule, not a Lean-success label. Model proofs remain
`model_proven`; only a woven VIR-to-artifact refinement chain with trust,
independent replay, and target correspondence can become `artifact_verified`.
RVFI/SBY, Sail, QEMU/FPGA, CPU/SIMD, and Vulkan/RenderDoc rows stay HOLD until
their exact host/board artifacts are available.

Inspect the architecture, detail design, and system-test plan for the resume
owners and evidence boundaries.
