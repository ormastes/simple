# StarFive VisionFive 2 NVMe storage NFRs

- NFR-001: Identification performs zero writes.
- NFR-002: Ambiguous, changed, in-use, mounted, or boot-source devices fail closed.
- NFR-003: Receipts contain no credentials.
- NFR-004: Partition arithmetic is overflow-safe and 1 MiB aligned.
- NFR-005: Persistence evidence is collected only after remount.
- NFR-006: Missing hardware is BLOCKED (exit 2), never PASS.
- NFR-007: Common PCI/NVMe code contains no StarFive constants.
- NFR-008: Checkers emit stable machine-readable keys.
