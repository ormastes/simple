# Web layout manager non-functional requirements

- NFR-WLM-001: Identical inputs produce identical frontiers, boxes, mappings, and receipt hashes.
- NFR-WLM-002: Incremental output equals the full CPU oracle for admitted fixtures.
- NFR-WLM-003: A receipt identifies the visited islands and any fallback reason.
- NFR-WLM-004: No full-tree scan occurs in the manager after the adapter has built the snapshot.
- NFR-WLM-005: No process or environment access is introduced in browser leaf modules.
