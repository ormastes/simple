# LLM Caret Messaging

Use the `llm-caret-messaging` MCP server for intentional chat actions. Read
bounded context before acting, use canonical task and message IDs, keep private
content in direct rooms, publish durable outputs as artifacts, and report only
truthful receipt evidence. Lifecycle hooks enqueue local events and must not
perform external transport delivery.
