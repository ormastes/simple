# SPipe Plugin for Antigravity (`agy`)

Provides SPipe skills (`spipe`, `spipe-loop`, `spipe-research`, `sp-dev`, `sstack`) for Antigravity (`agy`) alongside the `spipe`, `simple-mcp`, and `simple-lsp-mcp` MCP servers.

## Install

```bash
sh config/mcp/install.shs
```

Or manually with the Antigravity CLI:

```bash
agy plugin validate --strict plugins/spipe
agy plugin install plugins/spipe
```
