(lane macro-rr-invalidation; design doc/05_design/compiler/macro_rr_invalidation.md §4)

Semantic transition
-------------------
`src/compiler/80.driver/driver_build/incremental.spl#DependencyEntry` gains one
field, `macro_input_root: text`: the fold of the expansion inputs the source
consumed at publication (`macro_rr_contract_v1.macro_input_root_v1`, an
algorithm-tagged macro digest, "" when unknown). It is recorded by
`build_cache_record_entry_with_fp` and checked by `build_cache_entry_is_valid`
through `incremental_macro_input_root_valid_v1`: the entry is valid only when
the root recomputed against the CURRENT definer companions equals the recorded
one; "" recorded is valid only when the source has no macro uses now. The
dependencies' macro effect surfaces additionally ride inside the existing
`deps_iface` fold rows (`dep_iface_gate_record_v2` / `dep_iface_gate_valid_v2`),
so position 33 (`entry_deps_iface`) now also moves on a dependency's generated
public surface or exported macro contract change. Every unknown fails closed
(no reuse), never open.

Model boundary
--------------
The live-key positions bound to DependencyEntry (31 `entry_source_content`,
32 `entry_dependencies`, 33 `entry_deps_iface`, 34 `entry_interface_digest`,
35 `entry_module_witness` in Generated/LiveKey.lean) are unchanged in meaning
and order. `macro_input_root` is NOT added to the LiveKey schema in this
change: it is a validation-gate input compared for equality at admission, and
the generator (`src/app/gen_cache_model/main.spl`) that produces
Generated/LiveKey.lean and `inputs_accounted` cannot be run on this host (no
self-hosted binary). Follow-up obligation, tracked in the lane's plan row
(doc/03_plan/compiler/generics/generics_refactoring_formal_verification_plan_2026-10-31.md
§1A.0 `RR-M`): add `entry_macro_input_root` (scalar) to the live-key schema,
regenerate, and prove `entry_macro_input_root_live_change_visible`. Until then
the field's invalidation property is covered by the executable specs only
(`test/03_system/compiler/feature/macro_rr_invalidation_spec.spl`,
`test/01_unit/compiler/cache/macro_rr_invalidation_v1_spec.spl`), which are
UNRUN on this host. No production authority or publication claim follows.
