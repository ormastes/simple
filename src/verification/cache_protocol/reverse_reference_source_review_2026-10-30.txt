Reverse-reference model source review — 2026-10-30

Semantic transition
-------------------
The bounded RR model now treats an unsealed consumer as a failed candidate
generation regardless of whether an earlier receipt exists. A current
projection contains only reads from sealed current manifests. The caller may
continue to read and retain its prior immutable receipt, but this model never
copies that history into a new candidate or presents it as a current result.
An explicitly sealed manifest with zero reads remains a valid empty consumer.
An unsealed entry anywhere in the list rejects the complete candidate.

Model boundary
--------------
`ReverseReferenceV2` models only edge membership and sealed/unsealed
projection success. It does not model production coverage markers, use/count
semantics, canonical scope inventory, pinned forward-root authority, durability,
SOSIX publication, or recovery. A missing manifest is represented as an
unsealed manifest by the model; there is no separate optional-manifest value.
No production authority or publication claim follows from these Lean results.
