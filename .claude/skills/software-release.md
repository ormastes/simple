# General Protected Software Release

Use `doc/07_guide/infra/software_release.md`. Preserve isolated session authoring, one canonical version manifest, reviewed exact bug-fix backports for beta/maintenance lines, immutable build-once candidates, exact signed-tag promotion without rebuild, and non-destructive withdrawal. At bounded beta/bootstrap checkpoints, compare exact `main` and `release/X.Y` snapshots read-only. Backport or forward-port only an operator-selected exact reviewed fix through an isolated branch, renewed evidence, divergence receipt, and protected CAS integration. `main` remains development trunk and never tracks or becomes the release line. Require verified focused and whole-suite evidence. Ask before external push/publication; missing authority remains blocked.
