# General Protected Software Release

Use `doc/07_guide/infra/software_release.md`. Preserve isolated session authoring with one branch and worktree, one canonical version manifest, reviewed exact bug-fix backports for beta/maintenance lines, immutable build-once candidates, and exact signed annotated tag promotion without rebuild. At bounded beta/bootstrap checkpoints, compare exact `main` and `release/X.Y` snapshots read-only. Backport or forward-port only an operator-selected exact reviewed fix through an isolated branch, renewed evidence, divergence receipt, and protected CAS integration. `main` remains the development trunk and never tracks or becomes the release line. Rollback redeploys; withdrawal preserves published identity. Require verified focused and whole-suite evidence. Ask before external push or publication; missing authority remains blocked.
