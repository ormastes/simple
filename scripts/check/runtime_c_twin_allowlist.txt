# Reviewed C runtime twins: symbols that two objects of the hosted bundle both
# define with DIFFERENT bodies. Checked by
# scripts/check/check-runtime-c-twin-bodies.shs; pairs with identical bodies
# need no row.
#
#   <symbol> TAB <definers, link order> TAB <ELF winner> TAB <class> TAB <hash> TAB <reason>
#
# class:
#   benign         same observable behaviour on the POSIX hosts this bundle links on
#   weak-fallback  one copy is weak by design, so the strong owner wins in any order
#   design         the bodies differ observably; the reason says how and why it stands
#
# The hash covers the winner name and both normalized bodies. Editing either
# body or changing the link order fails the check until the pair is read again
# and the row updated (`--rows` prints current hashes). Do not paste a new hash
# without comparing the bodies: that is the review this file records.
# On Mach-O the SPL_RUNTIME_NATIVE_TWIN copies in runtime.c are weak, so the
# other definer runs there; a row is only safe if it holds for both winners.
