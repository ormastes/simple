# Opt-outs for the class (a) leg of check-non-optional-nil-return.shs.
#
# A row says: this extern is nil-capable in the interpreter, and its
# declaration may nevertheless stay non-optional. Format, one per line:
#     <extern> <return type, no spaces> <written reason, rest of the line>
# The reason is REQUIRED: a row without one is an ERROR (exit 2), because an
# opt-out is a statement and a statement needs its justification. The pair
# (extern, type) applies to every file that declares it and to the
# rt_alias_map.sdn decl. A row that no longer matches a nil-capable
# non-optional declaration is STALE and fails the gate.
#
# Only declarations whose type is the untyped raw-ABI word (`i64`, `i32`),
# `RuntimeValue`, `auto` or `Any` belong here, and each reason below was written
# after reading the Rust impl under
# src/compiler_rust/compiler/src/interpreter_extern/. `T?` is the fix for every
# typed declaration (text, [text], [u8], Expr, bool ...); those are ratcheted in
# non_optional_nil_return_classa_baseline.txt instead. `rt_enum_payload -> Expr`
# is deliberately NOT here.
#
