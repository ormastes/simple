# guard_wiring_optout.txt -- guards deliberately NOT wired into a hook or CI.
#
# Format:  <script-basename><whitespace><why it is not a gate>
# A reason is REQUIRED. check-guard-wiring.shs rejects a bare basename: an
# unexplained skip is exactly the state this file exists to eliminate.
# THIS IS A RATCHET BASELINE, NOT AN AMNESTY.
# Seeded 2026-08-01 from the audit in
# doc/08_tracking/bug/check_script_wiring_orphans_2026-08-01.md, which found 366
# of 413 tracked shell guards reachable from no hook and no workflow. Listing
# them here does not bless them; it makes the debt countable and stops the set
# from growing silently. Shrinking this file is a follow-up program with an
# owner.
# DO NOT add a line here to make a red build green. Wire the guard instead. A
# line here is a written claim that the script is not meant to gate anything --
# usually because it needs hardware, a GPU, a browser runtime or an emulator
# that a general-purpose CI runner does not have.
# check-guard-wiring.shs also FAILS on a stale entry: one that is now wired, or
# one whose script no longer exists. Remove entries as guards get wired.
# ---------------------------------------------------------------------
# Added 2026-08-30. Each line below was triaged by READING the script,
# not by pattern-matching its name. Every one of these genuinely cannot
# run on a general-purpose hosted runner; the dominant blocker is
# needing an admitted Stage-3/Stage-4 pure-Simple compiler
# ($SIMPLE_BIN native-build, or sourcing lib/bootstrap-stage3-provenance.shs),
# followed by GPU device readback and full cargo builds. Guards that only
# need clang/nm/readelf/objdump/llvm-cov were NOT opted out -- they are
# wired into repo-hygiene.yml instead.
# ---------------------------------------------------------------------
