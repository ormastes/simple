# runtime_source_list_parity_baseline.txt
#
# Frozen membership map for scripts/check/check-runtime-source-list-parity.shs.
# One row per owned *.c under src/runtime/ (vendor/** excluded):
#     <path relative to src/runtime>  <lanes that compile it>
# Lanes: seed   = native_project/tools.rs (core-C capsule archive)
#        simple = 70.backend/backend/runtime_compiler.spl (native product build)
#        rust   = compiler_rust/runtime/build.rs (interpreter/seed crate)
#        none   = compiled by NO list (test/, startup/baremetal/, scilib/,
#                 platform/ and friends -- legitimately not in a runtime link)
# Unity '#include "x.c"' coverage is expanded before the signature is taken.
#
# This file IS the explicit per-lane allowlist: legitimate divergence
# (hosted_win32.c seed+rust only, runtime_sdl2.c simple-only, ...) is a row
# here, not a special case in code. Regenerate ONLY for reviewed changes --
# a FAIL naming a changed membership is real drift and regenerating hides it.
#
# 2026-09-06, reviewed update of FOUR rows already true at origin/main (the
# gate was red at origin itself, blocking every push from a host with a working
# hook). All four are the SAFE direction — no list entry was DROPPED, which is
# the defect class this gate exists to catch:
#   runtime_coverage_core.c, runtime_memory.c, runtime_process_owned.c each
#     GAINED the seed list (more coverage, not less).
#   slang_ggml_shim.c is new and belongs to no static list by design: it is the
#     dynamic SFFI shim, dlopen-ed from a separately built shared library, so
#     "none" is correct rather than a missing-symbol risk.
