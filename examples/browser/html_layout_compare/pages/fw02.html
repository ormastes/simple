A browser engine transforms structured HTML documents and CSS stylesheets into an interactive visual representation on screen across desktop and embedded viewports.

After parsing tokens and building the formatting tree, layout resolves block cursors, floated boxes, flex tracks, and inline line boxes with kerning-aware metrics.
